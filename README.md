## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/pranavvv0016/Machine-Learning-Fundamentals-.git
```

### 2. Navigate to the repository

```bash
cd Machine-Learning-Fundamentals-
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install the dependencies

```bash
python -m pip install --upgrade pip
python -m pip install numpy pandas matplotlib scikit-learn jupyter
```

### 5. Launch Jupyter Notebook

```bash
jupyter notebook
```

Alternatively, open the repository in VS Code and select the Python interpreter associated with your virtual environment.
